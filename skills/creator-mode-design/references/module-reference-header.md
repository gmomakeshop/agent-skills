## $module.header

全ページ共通のヘッダーです。`_module_/header.html` に HTML を記述し、各ページのベーステンプレートから `<{$module.header}>` として読み込まれます。CSS・JavaScript は定義できないため、装飾は Tailwind のユーティリティクラスで行います。

```html
<{$module.header}>
```

## デザインポイント

ロゴやナビを置くだけでなく、全ページの顔として魅力と使いやすさを高める工夫を挙げる。

### 世界観を出すロゴまわり

ロゴのサイズ・余白・フォントでブランドの第一印象を作る。ロゴが設定されている場合は、ショップ名よりロゴを優先的に使用する。

### お知らせバー

ヘッダー上部に送料無料やセールの一言を載せ、来訪直後に推したい情報を届ける。

### 探しやすいナビゲーション

項目が多い場合はメガメニューやカテゴリーの階層表示で、目的地へ素早く移動できるようにする。

## チェックリスト

実装が終わったら動作をセルフチェック、ユーザーにも確認してください。以下はチェックすべき項目の一例です。

- スマホサイズでハンバーガーメニューが開閉するか・デザインが崩れていないか
- 各ボタンは動くか
- 直接リンクを指定するのではなく、独自タグを使ったリンクを指定しているか
