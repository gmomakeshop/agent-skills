# 特定商取引法ページ

必須

## 実装手順

1. テンプレート `templates/standard/html/contract.html` を作業フォルダの `standard/html/contract.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

法令で求められる情報を正確に載せたうえで、読みやすさを高める工夫を挙げる。

### 表組みで整理する

項目名と内容を対にした表にし、目的の項目をすぐ見つけられるようにする。装飾より正確さと可読性を優先する。

## チェックリスト
