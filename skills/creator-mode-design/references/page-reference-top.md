# トップページ

必須

## 実装手順

1. テンプレート `templates/standard/html/top.html` を作業フォルダの `standard/html/top.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

基本的なパーツを並べるだけでは他店と似た印象になりやすい。ここでは魅力と独創性を高める工夫を挙げる。

### 没入感のあるファーストビュー

メインビジュアルにフェードイン・パララックス・動画背景などの動きを加え、開いた瞬間に世界観へ引き込む。基本的に、ヒーロー画像はクリエイターモードのタグを使用して出力する。そうすることで、コードの編集することなくヒーロー画像を変更できる。

### 業界・コンセプトに応じた独創的なパーツ

ショップの業界やコンセプトを体現するパーツを1つ作り込むと、トップの印象が決まる。汎用的なパーツを並べるのではなく、扱う商材に合った見せ方を選ぶ。

- アパレル: 着用イメージを物語として見せるLookBook、コーディネート提案
- 食品・コスメ: 素材やこだわりを伝えるストーリー、使用シーンの訴求
- 雑貨・インテリア: 暮らしの中での使い方が伝わるスタイリング写真

業界に合った仕掛けが思い浮かばない場合は、診断・地図状の導線・こだわった登場演出など、コンセプトに沿った仕掛けを検討する。

### レビューの実装

レビュー機能は、新レビュー（U-KOMI）と旧レビューのどちらを使用しているかで実装方法が異なる。実装前に必ずどちらを使用しているかをユーザーにヒアリングする。

新レビュー（U-KOMI）を使用している場合は、以下のタグでトップページにレビュースライダー（全商品のレビューをスライダー形式で表示）を設置できる。

```html
<div class="review-container" data-review-type="product" data-action="slider" data-review-count="10" data-morereview-page="1" data-morereview-page-link="/view/page/review-list" data-morereview-page-text="レビューをもっと見る"></div>
```

「もっと見る」ボタンのリンク先には、全商品のレビュー一覧を設置したページ（page-reference-review-listを参照）のURLを指定する。URLが異なる場合は `data-morereview-page-link="○○"` の部分を当該URLに変更する。
