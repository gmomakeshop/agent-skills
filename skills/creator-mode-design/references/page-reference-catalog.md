# カタログページ

任意

## 実装手順

1. テンプレート `templates/standard/html/catalog.html` を作業フォルダの `standard/html/catalog.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

商品を均一に並べるだけでなく、見て楽しいカタログにする工夫を挙げる。

### 雑誌のようなレイアウト

大小のグリッドや余白の取り方で、ただの一覧ではなくカタログらしい誌面感を出す。

### 世界観を伝える構成

掲載商品をテーマやシーンでまとめ、画像のトーンを揃えると、ブランドの世界観が伝わる。
