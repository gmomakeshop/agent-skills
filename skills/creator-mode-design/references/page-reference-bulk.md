# まとめ買い割引ページ

任意

## 実装手順

1. テンプレート `templates/standard/html/bulk.html` を作業フォルダの `standard/html/bulk.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

対象商品を並べるだけでなく、まとめ買いのお得感を強く伝える工夫を挙げる。

### お得感を演出する

「2点で10%オフ」など割引条件を大きく見せ、通常価格との差や割引後の金額を視覚的に示す。

### セットで提案する

相性のよい商品を組み合わせて提案し、まとめて選びたくなる見せ方にする。
