# 会社概要ページ

必須

## 実装手順

1. テンプレート `templates/standard/html/company.html` を作業フォルダの `standard/html/company.html` にコピーする。

2. 必要なパーツを洗い出す。
3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

会社情報を載せるだけでなく、運営者の人柄やブランドへの信頼を伝える工夫を挙げる。

### ブランドストーリーを語る

設立の想いやこだわりを文章やビジュアルで伝え、共感につなげる。

### 地図やスタッフの写真

所在地の地図や、店舗・スタッフの写真を添えると、実在感と親しみが増す。
