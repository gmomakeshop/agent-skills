# 買い物カゴページ

必須

## 実装手順

1. テンプレート `templates/standard/html/cart.html` を作業フォルダの `standard/html/cart.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

カゴの中身を一覧するだけでなく、中身を編集しながら気持ちよくレジへ進ませる見せ方を作り込む。以下は買い物カゴを使いやすくする工夫の例。

### 数量の増減・削除をその場で完結させる

各商品に個数の増減ボタンと削除を分かりやすく配置し、操作した結果が小計・合計へすぐ反映されるようにする。誤って消しても戻せる導線を添えると、安心して数量を調整できる。これは買い物カゴの根幹なので必ず備える。

### 選んだバリエーション・オプションを明示する

商品名や画像の近くに、選択したサイズ・色などのバリエーションや、ラッピング・名入れといったオプションを並べて表示する。同じ商品を別々の組み合わせでカゴに入れている場合でも、それぞれ何を選んだのかをひと目で見分けられるようにし、注文前の確認を助ける。

### 金額の内訳をひと目で伝える

商品小計・送料・割引・合計を整理して並べ、支払総額が一目で分かるようにする。「送料無料まであと◯円」のように、もう少し買う理由を添えてもよい。

### レジへの動線を最優先で守る

リッチな装飾や提案を載せても、レジへ進むボタンは常に見つけやすい位置に置く。スクロール追従や要所への再掲で、買いたくなった瞬間に押せるようにする。

### 空カゴを行き止まりにしない

カゴが空のときこそ、人気商品や特集へ魅力的に誘導し、買い物を続けたくなる出口を用意する。

## チェックリスト

実装が終わったら動作をセルフチェック、ユーザーにも確認してください。以下はチェックすべき項目の一例です。

- 個数の増減は機能するか
- 商品の削除は機能するか
- 選んだバリエーション・オプションが商品ごとに表示されているか
