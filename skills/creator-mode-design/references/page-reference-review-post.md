# 商品レビュー投稿ページ

任意

## 実装手順

1. テンプレート `templates/standard/html/review-post.html` を作業フォルダの `standard/html/review-post.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

フォームを置くだけでなく、投稿のハードルを下げ、書きたくなる工夫を挙げる。

### レビューの実装

レビュー機能は、新レビュー（U-KOMI）と旧レビューのどちらを使用しているかで実装方法が異なる。実装前に必ずどちらを使用しているかをユーザーにヒアリングする。

このページは旧レビュー用のレビュー投稿ページ。新レビュー（U-KOMI）を使用している場合、このページの実装は不要。商品詳細ページに設置するレビュー一覧タグ（`data-action="widget"`）にレビュー投稿ボタンが含まれるため、投稿はそこから行われる。

### まず星を選ばせる

星評価を大きく目立たせ、最初のワンクリックから入らせると書き始めやすい。

### 書き方をさりげなく示す

プレースホルダーで記入例を示し、何を書けばよいか迷わせない。

## チェックリスト

実装が終わったら動作をセルフチェック、ユーザーにも確認してください。
