# お知らせ一覧ページ

任意

## 実装手順

1. テンプレート `templates/standard/html/news-list.html` を作業フォルダの `standard/html/news-list.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

日付とタイトルを並べるだけでなく、読み物として惹きつける工夫を挙げる。

### 最新を大きく見せる

先頭の記事を大きく扱い、いま伝えたい情報を目立たせる。

### 一覧に表情をつける

本文の抜粋を添え、タイトルだけのリストより読みたくなる見せ方にする。
