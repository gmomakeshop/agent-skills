# 会員制／年齢確認ページ

任意

## 実装手順

1. テンプレート `templates/standard/html/verification.html` を作業フォルダの `standard/html/verification.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

確認を取るだけの画面でも、ブランドらしさを保ち、迷わせない工夫を挙げる。

### 第一印象でも世界観を保つ

来訪者が最初に出会う画面になりうるため、背景や配色でブランドの雰囲気を感じさせる。

### 選択を迷わせない

進む側のボタンを目立たせ、押し間違えない大きさ・間隔にする。メッセージは短く明確に。
