# 利用案内ページ

必須

## 実装手順

1. テンプレート `templates/standard/html/guide.html` を作業フォルダの `standard/html/guide.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

情報を載せるだけでなく、不安を解消し、安心して買えると感じさせる工夫を挙げる。

### アイコンやイラストで直感的に

支払い・配送・返品をアイコンや図で示すと、読まずとも要点が伝わる。

### FAQをアコーディオンで

よくある質問を開閉式でまとめると、長くならず目当ての答えに辿り着ける。
