# 商品カテゴリーページ

必須

## 実装手順

1. テンプレート `templates/standard/html/category.html` を作業フォルダの `standard/html/category.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

商品を並べるだけでなく、カテゴリーの世界観を伝え、回遊したくなる工夫を挙げる。

### カテゴリーのキービジュアル

カテゴリー固有のイメージ画像や説明を上部に置き、特集ページのような世界観を出す。

### 魅せる商品カード

ホバーで別カットに切り替わる、着用イメージを重ねるなど、カードひとつの見せ方で一覧の印象が変わる。

### ピックアップ枠

一覧の冒頭に注目商品を大きく見せる枠を設け、まず何を見てほしいかを示す。

### ビジュアルなサブカテゴリー導線

下位カテゴリーを画像つきタイルで見せ、探す楽しさと回遊を促す。

### レビューの実装

レビュー機能は、新レビュー（U-KOMI）と旧レビューのどちらを使用しているかで実装方法が異なる。実装前に必ずどちらを使用しているかをユーザーにヒアリングする。

新レビュー（U-KOMI）を使用している場合は、商品リストのループ内（各商品カード）に以下のタグを設置すると、スターレーティング（星の5段階評価）が表示される。

```html
<div class="review-summary-container" data-gname="<{$category.item.list[i].system_code}>" data-pid="<{$category.item.list[i].system_code}>" data-group="true" data-popup="false" data-action="summary"></div>
```

注意: U-KOMIのタグは、旧レビュー機能の有効判定である `<{if $review_item.is_enabled}>` のようなif文の外に設置する。if文の中に置くと、旧レビュー機能を無効化した際にU-KOMIのレビューも表示されなくなる。
