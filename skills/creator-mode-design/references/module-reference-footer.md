## $module.footer

全ページ共通のフッターです。`_module_/footer.html` に HTML を記述し、各ページのベーステンプレートから `<{$module.footer}>` として読み込まれます。CSS・JavaScript は定義できないため、装飾は Tailwind のユーティリティクラスで行います。

```html
<{$module.footer}>
```

## デザインポイント

リンクを並べるだけでなく、締めくくりとして世界観と次の行動を添える工夫を挙げる。

### 世界観を出す大きめのフッター

余白やビジュアルを使い、ブランドメッセージやキービジュアルで締めくくる。
