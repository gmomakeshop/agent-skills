# 商品検索結果ページ

必須

## 実装手順

1. テンプレート `templates/standard/html/search.html` を作業フォルダの `standard/html/search.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

検索結果を並べるだけでなく、探す体験を快適にし、目当てに出会わせる工夫を挙げる。

### 探している言葉に応える

検索キーワードを結果上部やヒット箇所で示し、「ちゃんと探せた」と感じさせる。

### 視覚的な絞り込み

色・価格帯・カテゴリーなどをアイコンやスライダーで絞り込めるようにすると、探す楽しさが増す。

### 0件で終わらせない

該当がないときこそ見せ場。人気商品・おすすめワード・カテゴリー導線を魅力的に提案し、回遊につなげる。

### レビューの実装

レビュー機能は、新レビュー（U-KOMI）と旧レビューのどちらを使用しているかで実装方法が異なる。実装前に必ずどちらを使用しているかをユーザーにヒアリングする。

新レビュー（U-KOMI）を使用している場合は、検索結果リストのループ内（各商品カード）に以下のタグを設置すると、スターレーティング（星の5段階評価）が表示される。

```html
<div class="review-summary-container" data-gname="<{$search.item.list[i].system_code}>" data-pid="<{$search.item.list[i].system_code}>" data-group="true" data-popup="false" data-action="summary"></div>
```

注意: U-KOMIのタグは、旧レビュー機能の有効判定である `<{if $review_item.is_enabled}>` のようなif文の外に設置する。if文の中に置くと、旧レビュー機能を無効化した際にU-KOMIのレビューも表示されなくなる。
