# プライバシーポリシーページ

必須

## 実装手順

1. テンプレート `templates/standard/html/policy.html` を作業フォルダの `standard/html/policy.html` にコピーする。

2. 必要なパーツを洗い出す。

3. コピーしたファイルの `<!-- ここをデザインする -->` の箇所に、design-referenceとsmarty-referenceを使用してコーディングする。

## デザインポイント

長い文章でも、目当ての項目に辿り着け、読みやすくする工夫を挙げる。

### 目次やアンカーで探しやすく

冒頭に目次を置き、見出しへ飛べるようにすると、長文でも目的の項目に素早く辿り着ける。

### 可読性を最優先に

見出しで項目を区切り、適度な行幅・行間で読みやすくする。装飾は控えめにする。
