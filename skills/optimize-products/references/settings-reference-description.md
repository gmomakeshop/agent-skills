# 商品説明文

顧客は機能を買うのではなく、機能がもたらす生活の変化を買う。説明文は読まれない前提で、最も読まれる冒頭にベネフィットを凝縮し、購入判断に必要な情報を過不足なく置く。

## ベストプラクティス

### 1. 冒頭の一文で「購入後に得られる最高の結果」を伝える

書き出しがスペックの羅列だと、自分に関係がある商品かを判断できずに離脱される。冒頭はキャッチコピーとして20〜40文字を目安に1文で書き、詳細は本文に回す。型は「数字活用型」「共感型」「疑問形」「ベネフィット直球型」の4つから商品に合うものを選ぶ。

- 悪い例：`珪藻土バスマット 60×40cm。吸水・速乾。厚さ9mm。`
- 良い例：`お風呂上がりの一歩目が、いつでもさらっと乾いている。`

### 2. たった一人のペルソナに語りかける

「誰でも使える」は誰にも刺さらない。年齢・職業・ライフスタイル・悩み・使用シーンまで具体的な一人を思い描き、その人物に語りかける文体で書く。書く前に「誰の」「どんな悩みを」「どの場面で」解決するかを1行で定義する。

### 3. 機能には「だから何が嬉しいのか」を必ず添える

「機能 → ベネフィット」のセットを基本構成にする。箇条書きの各行をこの形に統一すると、書き漏れを機械的に点検できる。専門用語はベネフィットに変換する（「高密度な分子構造で熱伝導を最適化」→「熱がムラなく広がり、料理が焦げ付きにくい」）。

```
・UVカット率95%　→　日焼けの原因となる紫外線をほぼカット。真夏の屋外でも安心
・約180g　　　　 →　長時間さしていても腕が疲れない軽さ
・折りたたみ可能 →　バッグのサイドポケットにすっと収まるコンパクトさ
```

### 4. 五感表現と具体的な数字で裏付ける

「高品質」「上質な」などの抽象的な形容詞は何もイメージさせない。視覚・触覚・味覚・嗅覚・聴覚に訴える言葉で使用体験を想起させ、強い表現には必ず数字の根拠を添える。「様々な」「多くの」「大幅に」も数字に置き換える。

- 悪い例：`たっぷり入る折りたたみ収納ボックスです。`
- 良い例：`容量32L。2Lのペットボトルが12本、まるごと収まります。`

### 5. 6W2Hで購入判断に必要な情報を網羅する

書く前に次の8要素をリストアップし、抜けを埋める。

| 要素 | 書くこと |
|---|---|
| What | 品名・型番・色・サイズ・素材・内容量 |
| Who | ブランド・生産者・作り手 |
| Whom | 誰向けの商品か |
| When | 使う時期・季節・限定性 |
| Where | 製造地・産地・使用場所 |
| Why | 選ぶ理由（品質・機能・解決できる悩み） |
| How | 使い方・お手入れ方法・選び方 |
| How much | 価格の根拠・送料・セット内容 |

すべてを文章にする必要はなく、スペック系は箇条書きや表で示す。送料・在庫などの取引条件はカートに入れる前に分かるようにする。写真で伝わる内容（色・形）は簡潔にし、写真で伝わらない内容（重さ・肌触り・香り・サイズ感）に文字数を使う。

### 6. キャッチコピー → ボディ → クロージングの3部構成にする

長い段落だけの説明文はスキャン読みする顧客に届かない。「キャッチコピー（導入1〜3文）→ ボディ（特長・仕様の箇条書き）→ クロージング（保証・限定性・送料無料など購入の後押し）」に組み立てる。全体は400〜650文字を目安にし、1文1情報・1段落2〜3文を上限にする。短すぎると不安が解消されず、長すぎると読み疲れて離脱される。

### 7. 最初の3行に結論を置く

スマートフォンで読まれる前提で作る。スクロールせずに見える最初の3行（約100文字）に「誰向けか・ベネフィット・価格に関わる条件」を置き、詳細スペックは後半に回す。横幅固定レイアウト（width指定の表・大きな画像）は横スクロールが発生するため、幅指定なしの箇条書き中心に組み立てる。

### 8. 見出し・太字・表で「読まなくても分かる」レイアウトにする

HTMLが使えるため、3〜5項目ごとに【特長】【サイズ】【お手入れ】のような小見出しを立て、スペックは表に、特長は箇条書きにする。太字は1ブロックに1〜2箇所まで。全文太字・多色・過剰な装飾はかえって何も目立たなくなる。段落間には空行を入れる。

### 9. 社会的証明とデメリットの正直な記載で信頼をつくる

販売実績・受賞歴・メディア掲載・レビューなどの客観的な事実は安心感を与える。レビューは年代・属性つきで1〜3件引用すると判断材料として効く。実績の数字には時点を添える。

同時に、注意点やデメリットも対応策とセットで正直に書く。購入前に納得した顧客だけが買うため、「思っていたのと違う」による返品を防げる。

```
・累計販売数10,000個突破（2025年9月時点）
・真鍮製のため、使い込むほどに色味が変化します。経年変化を楽しめる方におすすめです
```

### 10. レビューと問い合わせを説明文に還元する

月1回、レビュー・問い合わせ・返品理由を見返し、同じ指摘が2〜3件あればその回答を説明文に追記する。顧客が使う言葉（「サイズ感」「肌触り」）は次の顧客が検索・スキャンする言葉でもあるため、そのままの表現で反映する。

### 11. 文体・表記ルールを全商品で統一する

商品ごとに文体や表記がバラバラだと、回遊した顧客に雑な印象を与える。「です・ます調」「感嘆符は1説明文に1個まで」「数字は半角・単位併記」「機種依存文字・絵文字は使わない」「一人称と顧客の呼び方を固定」のようなルールを決め、新規登録時はルールに沿って書き、既存商品は売れ筋から順に直す。

### 12. メーカー説明文の流用と法令違反表現を避ける

仕入先の説明文をそのまま掲載すると、検索エンジンに重複コンテンツと判定され、他店との差別化もできない。必ず自社のターゲット視点で書き直す。

| カテゴリ | 避ける表現 | 修正の方向 |
|---|---|---|
| 化粧品 | 「シミが消える」「肌が若返る」（薬機法上の問題になるおそれがある効能効果の表現） | 「うるおいを与え、明るい印象の肌へ」 |
| 健康食品 | 「血糖値を下げる」「花粉症に効く」（医薬品的な効能効果と受け取られるおそれがある） | 「健康的な毎日の習慣に」 |
| 最上級表現 | 「日本一」「No.1」（根拠なし） | 調査の出典を明記する |
| 二重価格 | 販売実績のない価格との比較 | 販売実績のある価格のみ比較対照に使う（`references/settings-reference-pricing.md`） |

法令に関する記述は一般的な留意点であり、法的な助言ではない。個別の判断は所管官庁の資料または専門家に確認する。

## 症状別の打ち手

効果検証は、変更前の数値を控えたうえで2〜4週間後に同一指標を比較する。1回の変更は1〜2箇所に絞る。セール・広告出稿と重なった期間は比較から除外する。

| 症状 | 状態 | 打ち手 |
|---|---|---|
| アクセスはあるが買われない | 機能の羅列になっている | 各機能に「だから何が嬉しいのか」を添える（3）。改善後も動かなければ価格・画像へ切り分ける |
| 直帰率が高い・滞在時間が短い | 冒頭で自分ごと化できていない | 書き出しをベネフィットのキャッチコピーに差し替える（1） |
| 長くて読まれない | 段落だけで構成されている | 3部構成に組み替え、400〜650文字に整理する（6） |
| 価格でしか比較されない | 万人向けの無難な文章 | 一人のペルソナを設定し、その悩み・シーンに語りかける（2） |
| 「思っていたのと違う」返品が多い | 良いことしか書いていない | デメリット・注意点を対応策とセットで明記する（9） |
| カート落ちが多い | 取引条件が後出しになっている | 送料・返品条件・保証・お届け目安を説明文の段階で明示する（5） |
| 問い合わせが多い | 購入判断に必要な情報が抜けている | よくある質問を起点に6W2Hで抜けを点検して埋める（5） |
| 検索流入が少ない | メーカー説明文の流用 | オリジナルの文章に書き直し、検索語を自然に含める。狙う語は2〜3語に絞る（12、`references/settings-reference-seo.md`） |
| 競合と同質化している | 売り文句が同じ | 開発の背景・作り手のこだわり・試行錯誤のエピソードを語る |
| 初めての顧客に信頼されない | 客観的な裏付けがない | 販売実績・受賞歴・メディア掲載・レビューを盛り込む（9） |
| 高価格帯が買われない | 価格に見合う価値が伝わらない | 抽象表現を数字・産地・製法・権威付けに置き換える（4、`references/settings-reference-pricing.md`） |
| 季節・ギフト需要を逃す | 訴求が通年のまま | 需要期の4〜6週間前に利用シーンの描写を入れ替える。ギフトは贈る側の視点（包装・のし・直送・お届け日数）を追記 |
| 変更の効果が分からない | 検証していない | CVR・直帰率・カート落ち率・返品率・問い合わせ数を変更前後で比較する |
