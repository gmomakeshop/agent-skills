# 価格・割引・ポイント

販売価格・仕入価格・定価・割引・ポイントは、粗利をどう配分するかという一体の設計として扱う。個別に決めると合計で粗利を食い潰す。

法令・税務に関する記述は一般的な留意点であり、法的・税務的な助言ではない。個別の判断は所管官庁の資料または専門家に確認する。

## 価格

### 1. 仕入価格を入力する

粗利率を計算できないと以降の判断がすべて勘になる。粗利率 =（販売価格 − 仕入価格）÷ 販売価格 × 100。この粗利率が、割引・ポイント・送料・手数料に配分できる上限になる。

### 2. 隠れたコストまで原価に含める

仕入価格だけでは採算は見えない。1注文あたりの送料・梱包材・決済手数料・広告費を洗い出す。

例）仕入2,000円・販売3,000円で粗利1,000円でも、送料700円・決済手数料120円・梱包材100円を引くと利益は80円。広告経由なら赤字。

### 3. 粗利率は自店の実績と相場で判断する

適正水準は業種・商材で大きく異なるため、固定の目安を当てはめない。同カテゴリの自店商品の粗利率、仕入先から聞ける相場、過去の自店実績と比較して、大きく下回る商品を洗い出す。

### 4. 販売価格は原価・目標利益・競合相場の3視点で決める

1つだけに頼ると偏る。

- 原価率ベース：販売価格 = 原価 ÷ 目標原価率
- 利益率ベース：販売価格 = 原価 ÷（1 − 目標利益率）
- 競合・市場比較：同等商品の相場に合わせ、差別化要素があれば上乗せ

計算 → 相場との突き合わせ → 商品の役割（集客用か利益用か）→ 端数調整、の順で決める。

### 5. 最初から安くしすぎない

値下げはいつでもできるが、値上げは顧客離れのリスクを伴う。初期価格は原価変動への余裕を持たせ、集客は期間限定の割引やクーポンで行う。

### 6. 相場から大きく外れた価格をつけない

著しく高いと比較段階で候補から外れ、著しく安いと品質を疑われる。相場より高くする場合は、その根拠（素材・製法・保証）を説明文で示せるかを基準にする。

### 7. 端数価格を使い分ける

2,980円は「2,000円台」、3,000円は「3,000円台」として認識され、価格帯の印象が1段階変わる。ただし高級品・ギフト商材では、キリのよい価格のほうが品質感を支えることがある。

### 8. 商品の役割に応じて価格戦略を選ぶ

全商品を同じ発想で値付けしない。

| 戦略 | 使いどころ |
|---|---|
| プレミアム価格 | こだわり・希少性のある商品。品質とブランド価値を示す |
| ポートフォリオ価格 | 目玉商品は低粗利で集客し、同時購入される商品で利益を確保する |
| ライフサイクル価格 | 導入期は低めで認知を取り、定着後に適正価格へ |
| ダイナミック価格 | 季節商品・型落ち品など、需要と在庫で見直す |

### 9. 定価は根拠のある価格だけを使う

定価を販売価格より高く設定すると打ち消し線表示になり、お得感を演出できる（アンカリング効果）。ただし販売実績のない定価との比較は、景品表示法上の問題（有利誤認表示）になるおそれがある。

比較対照には、あらかじめ公表されているメーカー希望小売価格か、実際に相当期間販売した実績のある価格を使う。「相当期間」の判断基準は消費者庁の価格表示に関する資料を確認する。

### 10. 税率を商品カテゴリに合わせて設定する

適用される税率は商材によって異なり、飲食料品と酒類・外食では扱いが変わる。みりん・栄養ドリンク・おまけ付き食品など判断が分かれる商材は、国税庁の資料または税理士に確認する。消費者向けの価格表示についても、求められる表示方法を確認しておく。

## 割引

### 11. 目的を決めてから設計する

目的によって適切な手法がまったく異なる。

| 目的 | 手法 |
|---|---|
| 新規顧客の獲得 | 初回購入割引・クーポン |
| 在庫消化 | クリアランスセール・まとめ買い割引・おまけ付き |
| 客単価アップ | 購入金額別割引・送料無料ライン・まとめ買い割引 |
| リピート促進 | ポイント・再購入クーポン・購入回数特典 |
| 短期の売上づくり | タイムセール・期間限定セール |

### 12. 割引率は行動を促せる水準にする

割引率が小さすぎると「待てば次がある」が勝ち、利益だけ削れて行動を促せない。実施するなら実感の出る水準まで上げ、届かないならやらない。

### 13. 期間を短く区切り、終了日時を必ず設定する

割引期間が長引くと顧客はその価格を通常価格として認識し、セール終了後に購入率が落ちる。終了日時を設定せず放置すると常時セール状態になり、通常価格での販売実績も積み上がらなくなる。期限があること自体が購買動機になる。

目安：タイムセールは24〜72時間、週末セールは3〜7日間、クリアランスは最長2週間。

### 14. 大幅割引は目的と頻度を限定する

大幅割引は在庫処分・フラッシュセール・年1〜2回の大型セールに限る。高頻度で実施すると、顧客が「次のセールまで待つ」と学習して定価で買わなくなる。

### 15. 実施前に利益への影響を計算する

割引後の1個あたり利益が残るか、何個売れれば原資を回収できるかを先に計算する。割引率の上限は粗利率から逆算する。

例）粗利率40%（販売5,000円・粗利2,000円）に20%OFF → 割引コスト1,000円・割引後粗利1,000円（実効粗利率20%）。粗利率30%の商品に30%OFFなら粗利ゼロ。

### 16. 対象を絞り、全商品一律にしない

全商品一律のセールは、割引しなくても売れていた商品の利益まで削る。在庫過多・季節終わり・旧モデルなど、割引する理由のある商品に絞る。

### 17. %割引と定額割引を価格帯で使い分ける

同じ値引き額でも見え方が変わる（フレーミング効果）。低価格帯は%表示、高価格帯は金額表示のほうが大きく感じられやすい。

例）2,000円の商品は「20%OFF」、50,000円の商品は「5,000円引き」。

### 18. 値下げ以外の手法で客単価を上げる

「安くする」ではなく「多く・高く買う理由を作る」。

| 手法 | 効果 |
|---|---|
| BOGO（1つ買うと1つ無料） | 2個分の在庫が動き、在庫処分と相性がよい |
| 無料ギフト・おまけ | 値下げせず付加価値で訴求する |
| まとめ買い割引 | 1注文あたりの点数が増える |
| 購入金額別割引 | あと少しで届く顧客の追加購入を促す |
| クーポンの利用最低金額 | 平均客単価の少し上に置くと、割引しながら客単価が上がる |

### 19. 送料無料は最低購入金額とセットで設計する

追加費用は購入直前の離脱要因になりやすい。ただし無条件の送料無料は全注文の利益を削るため、「○円以上で送料無料」と組み合わせる。

ラインは平均客単価の2〜3割上、かつ主力商品の価格の少し上に置く。商品ページとカートで「あと○円で送料無料」と残額を見せ、差額を埋めやすい低単価商品を併売する。

## ポイント

### 20. 割引は短期の起爆剤、ポイントは長期のリピート装置

割引・クーポンは「いま買う理由」、ポイントは「次も買う理由」を作る。新規獲得と在庫消化は割引で、リピートとLTVはポイントで、と役割を分ける。リピートを増やしたいのにセールを連発すると、セール時しか買わない顧客が集まる。

### 21. ポイントを未設定のまま放置しない

ポイントが未設定またはゼロだと、購入後に再来店の動機が何も残らない。

### 22. ポイント率は粗利率から逆算する

粗利率の高い商材は高め、低い商材は低めに設定する。低すぎると「貯まらない」と感じさせて動機にならないため、まず低めに設定し、リピート率を見ながら調整する。

### 23. %ポイントと固定ポイントを使い分ける

単価にばらつきがある商品群は%設定が公平。固定100ポイントだと3,000円の商品で3.3%相当、10,000円の商品で1%相当と不公平になる。特定商品を推したいときは固定ポイントのほうが訴求力が出る。

%設定では小数点以下が切り捨てられるため、低単価商品では実質還元率が表示よりわずかに下がる。

### 24. ポイントと割引の合計が粗利率を超えないようにする

合計コスト率 = ポイント率 + 割引率、実効粗利率 = 粗利率 − 合計コスト率。送料・手数料のバッファが残る水準に抑える。

例）粗利率40%にポイント5% + 割引20% → 実効粗利率15%。送料・手数料をカバーできない。

付与したポイントは将来の値引きの約束であり、未利用残高は債務として積み上がる。有効期限を設定し、残高を定期的に把握する。

## 症状別の打ち手

| 症状 | 状態 | 打ち手 |
|---|---|---|
| 利益が見えない | 仕入価格が未設定 | 仕入価格を入力し粗利率を確定させる（1） |
| 売れているのに利益が残らない | 隠れコストが粗利を食っている | 1注文あたりのコストを洗い出し実質利益を計算する（2） |
| 粗利率が低い | 仕入が高いか価格が安すぎる | 仕入先の見直し・ロット交渉、または価値の根拠を整えて値上げ（3） |
| 新商品の価格が決められない | 根拠がない | 計算 → 相場 → 役割 → 端数調整の順で決める（4） |
| 競合より高くて売れない | 価格差の根拠が伝わっていない | 説明文で根拠を訴求する。値下げは最後の手段（6、`references/settings-reference-description.md`） |
| 値上げしたいが顧客離れが怖い | 原価上昇に価格が追いついていない | 段階的に上げ、付加価値を同時に追加し、既存顧客には事前告知する |
| 価格がキリのよい数字のまま | 心理的な工夫がない | 端数価格に調整する（7） |
| 定価が未設定でお得感がない | 比較対象がない | 根拠のある定価を設定する（9） |
| 根拠のない定価で割引表示 | 架空の二重価格表示 | 公表された希望小売価格か販売実績のある価格のみ使う。なければ定価表示をやめる（9） |
| 税率がカテゴリと合っていない | 表示価格と税務処理が不正確 | カテゴリに合わせて是正する（10） |
| 低価格競争に巻き込まれている | 価格でしか比較されていない | プレミアム価格・ポートフォリオ設計へ移す。値引きの代わりにポイント・おまけで実質的なお得を演出する（8） |
| セールの決め方が分からない | 目的が曖昧 | 目的 → 手法 → 数字の順で設計する（11） |
| 割引しているのに反応がない | 割引率が実感の水準に届いていない | 対象と期間を絞って率を上げる。届かないならやめる（12） |
| セール価格が当たり前になった | 長期・高頻度の割引で価格の信頼が壊れた | 通常価格に戻し、通常価格での販売実績を作り直す（13） |
| 割引で売れたのに赤字 | 事前の利益計算がない | 実施前に1個あたり利益と損益分岐を確認する（15） |
| 全商品セールで利益が削れる | 定価でも売れる商品まで割引している | 対象を絞る（16） |
| 高単価商品の割引が響かない | %表示が実額を伝えていない | 金額表示に切り替える（17） |
| 低単価商品の割引が響かない | 金額表示が小さく見える | %表示に切り替える（17） |
| 客単価が低い | 1注文あたりの点数・金額が少ない | 購入金額別割引・まとめ買い割引に切り替える（18） |
| 在庫を処分したい | シーズン末・型落ちが残っている | クリアランス・BOGO・おまけ活用（`references/settings-reference-inventory.md`） |
| カゴ落ちが多い | 購入直前のコストで離脱 | 送料無料ラインを設定し「あと○円」を明示する（19） |
| 新規顧客が獲得できない | 初回購入のハードルが高い | 初回割引・初回クーポンを用意する。クーポンには利用最低金額を設定する（実質0円で購入できる設定は想定外の注文を招く） |
| 売上が平坦 | イベント性がない | 期間・数量を絞った限定セールで緊急性を作る |
| 新商品の初速が出ない | 認知が足りない | 先行予約・早期割引で初動を作る |
| 一律割引で利益が削れる | 全員に同じ特典を出している | 誕生日・記念日クーポン、購入回数に応じた段階的な特典に切り替える |
| セールの効果が分からない | 検証していない | 配布チャネルごとにクーポンコードを分け、客単価・転換率・リピート率・在庫消化率・利益で評価する |
| リピートの仕掛けがない | ポイント未設定 | ポイントを設定する（21、22） |
| ポイントが貯まる実感がない | 率が低すぎる | 粗利率に合わせて引き上げる（22） |
| 還元率が商品ごとに不公平 | 単価がばらつくのに固定ポイント | %設定に切り替える（23） |
| 特定商品を後押ししたい | %では訴求力が足りない | 対象商品だけ固定ポイントを期間限定で増量する（23） |
| ポイントと割引で利益が消えた | 同じ粗利を取り合っている | 合計コスト率に上限を設ける（24） |
| セールばかりでリピートしない | 短期施策だけになっている | 新規は初回クーポン、リピートはポイント+再購入クーポンに役割分担する（20） |
