# 商品画像

顧客は実物を手に取れないため、画像が「店頭で手に取って確かめる」行為の代替になる。一覧で選ばれる役割（1枚目）と、ページ内で不安を解消する役割（2枚目以降）を分けて設計する。

## ベストプラクティス

### 1. 1枚目は「何の商品か」が一瞬で伝わるカットにする

1枚目は一覧・検索結果のサムネイルとして競合と並ぶ。白背景・正面・商品全体を明るく写し、商品が画面積の大半を占める構図にする。背景に家具や人物が写り込んだ使用シーン写真は、サムネイルでは商品が埋もれて判別できない。

### 2. 1枚目にテキスト・バナー的な加工を載せない

「送料無料」「ランキング1位」などの文字を重ねると、サムネイルでは文字がつぶれて読めず、商品の視認性だけが下がる。チラシのような見た目はショップの信頼感も損なう。訴求文言は2枚目以降の説明画像に回し、枠線・透かし・過剰な装飾はどの画像でも避ける。

### 3. 正方形で統一し、軽さと精細さを両立する

小さすぎる画像は拡大でぼやけ、重すぎる画像は表示を遅くする。800×800px以上（ズーム重視なら長辺1,000〜1,600px）の正方形で統一し、JPEG・PNG・WebPで書き出す。容量が200KBを超えるファイルは自動リサイズされるため、アップロード前に圧縮して意図しない劣化を防ぐ。ファイル名は半角英数字にする。

### 4. 角度・種類の異なる画像を5〜8枚組み合わせる

1種類の写真では伝わらない情報が残り、購入をためらわせる。商品に合わせて次のタイプを組み合わせる。

| タイプ | 内容 |
|---|---|
| 個別ショット | 白背景に商品単体を正面・背面・サイド・俯瞰から |
| ズームアップ | 素材・縫い目・質感・印刷などのディテール |
| スケールショット | 手元・日用品と並べてサイズを明示 |
| ライフスタイル | 実際の使用シーンで「自分が使う姿」を想起させる |
| グループショット | セット内容・カラー展開・関連商品をまとめて見せる |
| パッケージショット | 外箱・梱包・開封体験を視覚化する |

### 5. サイズ感が誤解なく伝わるカットを必ず入れる

寸法の数字だけでは大きさを体感できず、「思っていたより小さい／大きい」は返品・低評価の定番原因になる。手に持った写真、身近な日用品との比較、着用・設置した状態など、大きさの基準が一緒に写ったカットを1枚は入れる。寸法線入りの説明画像を2枚目以降に置くのも有効。

### 6. 色・質感を実物に忠実に写す

掲載色が実物とずれていると、注文は取れても返品・クレーム・低評価で返ってくる。

- ホワイトバランスを光源に合わせる（白い紙が白く写る状態を基準にする）
- 室内照明は消し、自然光と人工光を混ぜない
- カラー展開のある商品は全色を同じ光源・同じ設定で撮影する
- 彩度を上げる加工は最小限にとどめる

### 7. 使用シーンの画像で「自分が使う姿」を想起させる

白背景のスタジオショットは比較には適しているが、生活にどう馴染むかは伝えられない。「誰が・いつ・どこで・どう使うか」を決めてから撮る。調理シーン、モデル着用の全身コーデ、屋外での実使用、デスクに配置した状態、盛り付け、部屋に設置した状態など、商材に合わせて選ぶ。

### 8. 顧客の不安から必要なカットを逆算する

撮影前に「この商品を買う人は何を不安に思うか（素材感・サイズ・色・耐久性）」を洗い出し、それに答えるカットの一覧を先に作る。あわせて同ジャンルの人気店がどんな画像を載せているかを確認する。

撮影直前の清掃は最も低コストで画質を上げる手段。ほこり・指紋・シワが写ると高品質な商品でも安っぽく見える。三脚で画角を固定し、同条件で全カットを撮り切る。

### 9. 光と背景を商品に合わせて整える

高価な機材は不要。窓際の自然光（曇りの日や午前〜正午の柔らかい光が扱いやすい）と白いレフ板（発泡スチロール板で代用可）だけでも質感は伝わる。フラッシュの直当ては質感と立体感をつぶす。

背景は比較しやすい白が基本。光沢が価値の商材（ジュエリー・時計）は黒背景で高級感を、雑貨・食品は木目調でナチュラル感を出す。小物は最小限にし、主役が商品であることを崩さない。

### 10. 構図とアングルを使い分ける

| 用途 | 構図・アングル |
|---|---|
| 1枚目 | 日の丸構図＋正面（何の商品かを最速で伝える） |
| ディテール | 水平〜やや俯瞰で寄り、ピントを質感に合わせる |
| ライフスタイル | 三分割構図・対角線構図で生活の中の商品を見せる |
| 全体像 | 俯瞰でセット内容・形状を見せる |

全カットが同じアングルだと、枚数があっても情報が重複する。

### 11. ショップ全体で画像のトーンを統一する

商品ごとに背景・明るさ・構図がバラバラだと、一覧が雑多に見えて信頼感が下がる。「白背景・1:1・商品占有率○%・自然光・影は薄く残す」のようなルールを決め、誰が撮っても同じトーンになるようにする。

### 12. スマートフォンでの見え方を基準に最終確認する

画像は編集画面より大幅に小さく表示される。公開前に実機で次を確認する。

- 一覧のサムネイルサイズで何の商品か判別できるか
- ディテールカットは画面幅でも質感が分かるか
- 説明画像の文字はピンチ操作なしで読めるか
- 1枚目から順に見て、疑問が順番に解消される並びになっているか

## 症状別の打ち手

| 症状 | 状態 | 打ち手 |
|---|---|---|
| 一覧でクリックされない | 1枚目がサムネイルで判別できない | 白背景・正面・商品全体のカットに差し替える（1）。商品名前半とあわせて見え方が決まる（`references/settings-reference-product-name.md`） |
| 1枚目が文字だらけ | 訴求を詰め込んで商品が見えない | 1枚目はテキストなしの商品単体、訴求は2枚目以降へ移す（2） |
| 画像が1枚しかない | 疑問に答えられていない | 正面・背面・ディテール・サイズ比較・使用シーンの5枚構成にする（4） |
| サイズ違いの返品がある | 寸法の数字だけで体感できていない | 手持ち・日用品比較・寸法線入り画像を追加する（5） |
| 色違いのクレームがある | 光源か加工で掲載色がずれている | 自然光下でホワイトバランスを合わせて撮り直す。カラー展開は全色同条件で（6） |
| アクセスはあるが買われない | 不安に画像が答えていない | 購入前の不安を列挙 → 各不安に答える画像があるか点検 → 人気店と枚数・種類を比較（8） |
| 写真が暗い・素人っぽい | 照明と準備の問題 | 清掃しシワを伸ばす → 窓際の自然光＋白レフ板、三脚固定で撮影（9） |
| 使用イメージが湧かない | スタジオショットのみ | 使用シーンのライフスタイル画像を追加する（7、10） |
| カラー・サイズが選びにくい | バリエーションの違いが見えない | 全色・全サイズを同条件で撮影し、グループショットも追加する（4、6） |
| 高単価なのに価値が伝わらない | 品質の根拠が画像にない | 縫製・素材・仕上げのズームアップを追加する。光沢商材は黒背景で高級感を出す（4、9） |
| ギフト用途で動かない | 届いたときの見え方が分からない | 化粧箱・ラッピング・開封のカットを追加する（4） |
| 表示が遅い・拡大でぼやける | サイズ・容量が適正でない | 800×800px以上に統一し、圧縮して1枚200KB前後に収める（3） |
