# 売上データ調査

注文・商品・会員データを組み合わせ、「どこに問題があるか」を数字で掴んでから改善を提案する。商品ごとの集計はシステム商品コードで行う。

## 取得するデータの期間

デフォルトは **直近12ヶ月**（季節を一巡でき、ほとんどの観点をまかなえる）。データ量が膨大で取得が重い場合は、必要な観点へ絞って期間を短縮してよい。

| 用途（主な観点） | 推奨期間 | 理由 |
|---|---|---|
| 全体の状況把握（デフォルト） | 直近12ヶ月 | 季節を一巡できる |
| 売上推移の前年同期比較（2） | 直近3ヶ月 ＋ 前年同期3ヶ月 | 2区間を厳密に比較するため。連続15ヶ月を取れない場合はこの2区間だけ取得 |
| 季節性・購買タイミング（5・15） | 直近12〜24ヶ月 | 山谷を1〜2周期分見て再現性を確認するため |
| リピート・LTV・定期購入（16・17） | 直近24ヶ月 | 購入間隔の数周期分を見ないと実態が見えないため |
| 在庫回転日数・直近の売れ行き（10・11） | 直近1〜3ヶ月 | 現在の販売ペースで算出するため。古い期間を混ぜると鈍る |
| 値引き・ポイント反応（12） | 割引実施期間 ＋ 直前の通常期間 | 割引あり期間と通常期間を対照するため |

## 注意

- **アクセス数そのものは取れない**。流入が問題かどうかは、売上推移・類似商品との比較・サイト内検索ヒットから間接的に推定する
- **ページタイトル・メタディスクリプションは取得しない**。個別設定が空でも一括設定のテンプレートが実ページへ自動反映されるため、商品単体のデータでは空欄を設定不足と判定できない
- **SEOはユーザーからの明示的な要望があったときだけ扱う**（`references/settings-reference-seo.md`）

## 18の調査観点

売上の因数分解は **売上 = 販売数 × 単価**。「販売数が少ない（流入・訴求の問題）」か「単価が低い（価格・客単価の問題）」かを切り分けると、次に見る観点が絞られる。

### 1. 売上貢献度

**問い**: この商品はお店の売上と利益にどれだけ貢献しているか？
**データ**: 注文データの商品別販売数・売上金額 + 商品データの仕入価格

ABC分析（売上上位20%の商品が全体の80%を占めるか）で優先度をつける。

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 売上・利益率ともに高い | 優先投資すべき商品 | 商品名・画像・説明文・在庫を最優先で改善 |
| 売上は低いが利益率が高い | 売れれば利益の柱になる候補 | 商品名・検索語の見直しで露出増加 |
| 売上も利益率も低い | 廃番・値上げ・在庫処分の候補 | 価格見直しか取り扱い終了 |

### 2. 売上推移

**問い**: 伸びている商品か、落ちている商品か？
**データ**: 販売数・売上金額を複数期間で比較（例: 直近3ヶ月 vs 前年同期3ヶ月）

**売上の絶対値**と**トレンドの方向**は別物として捉える。

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 前年同期比で販売数が増加 | 成長中 | 在庫確保・訴求強化で伸びに乗る |
| 前年同期比で販売数が減少 | 需要の衰退または競合台頭 | 価格・説明文・画像の見直し、または廃番検討 |
| 単価は横ばいで販売数が落ちる | 流入・訴求の問題 | 商品名・説明文・検索語の改善 |
| 販売数は横ばいで単価が落ちる | 割引依存 | 割引頻度と利益率の見直し（`references/settings-reference-pricing.md`） |

### 3. 類似商品との比較

**問い**: 売れないのはこの商品だけか、似た商品ぜんぶか？
**データ**: 同カテゴリ・類似キーワードのショップ内商品の販売数・売上 + 対象商品の販売数

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 類似商品は売れているのに対象だけ売れない | 商品固有の問題 | 売れている類似商品とページ・価格を比較し差分を埋める |
| 類似商品も含めて全体に売れていない | カテゴリ全体・集客の問題 | カテゴリの訴求・集客の見直しを優先 |
| 自社の類似商品に売上が偏っている | ショップ内で共食い | 用途・ターゲットの違いを明確化、または商品の統合 |

### 4. 価格の妥当性

**問い**: そもそも、その値段で買いたいと思えるか？
**データ**: 販売価格・定価・仕入価格 + ショップ内の類似商品の価格帯

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 相場より明らかに高い | 価格だけで候補から外れている | 値下げ、または高い理由を説明文で明示 |
| 相場より安すぎる | 利益の取り損ね、または品質を疑われている | 値上げ余地の検討、安心感の訴求強化 |
| 定価と販売価格が同額 | お得感の演出がない | 二重価格表示・端数価格の検討 |
| 商品価格に対して送料が重い | 総支払額で割高に見えている | 送料込み価格・送料無料ライン・まとめ買い設計 |

### 5. 購買タイミング

**問い**: いつ売れる商品か？
**データ**: 注文日時を月別・曜日別・時間帯別に集計

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 特定の月に集中 | 季節商品・ギフト需要 | ピーク前の在庫補充、ピーク合わせのセール設計 |
| 特定イベント前後に集中 | 贈答・記念日需要 | イベント前の訴求強化、ギフト向け説明文 |
| 週末や夜間に集中 | 趣味・余暇に関係する商品 | 週末限定セール、夜間向けの配信 |
| 年間通じて平坦 | 販促で山を作れる余地あり | セール・キャンペーンで緊急性を作る |

### 6. 顧客属性

**問い**: 誰が買っている商品か？
**データ**: 会員IDで新規/リピートを判定 + 会員データの性別・年齢・会員ランク

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 新規比率が極端に高い | リピートの仕掛けがない | ポイント設計・再購入クーポン |
| リピート比率が高い | 固定ファンがいる | 説明文で「なぜリピートするか」を訴求 |
| 特定の性別・年代に集中 | ターゲット層が絞られている | 訴求文・画像をその層に合わせる |
| 高会員ランクに集中 | 優良顧客向けの商品 | 信頼している層向けに説明文・画像を調整 |

### 7. 地域

**問い**: どこで買われている商品か？
**データ**: 注文者・配送先の都道府県

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 特定地域に集中 | 地域ニーズが強い、または広告配信エリアの偏り | 地域別キャンペーン、送料訴求の強化 |
| 遠距離注文が多い | 配送コストの高い注文が多い | 送料設計・送料無料ラインの見直し |

### 8. 併売商品

**問い**: 何と一緒に買われている商品か？
**データ**: 同一注文に含まれる商品の組み合わせを集計（バスケット分析）

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 特定商品との同時購入率が高い | 自然なセット商品が存在する | セット販売・説明文でのクロスセル訴求 |
| ほぼ単品購入ばかり | まとめ買いの動機がない | まとめ買い割引・送料無料ラインの設計 |

### 9. 購入単価

**問い**: 1回の買い物でいくら使ってもらえているか？
**データ**: 注文合計金額・購入点数・まとめ買い割引額・送料

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 1点購入ばかりで客単価が低い | クロスセルの余地がある | 説明文でのレコメンド・まとめ買い訴求 |
| 送料が発生している注文が多い | 「あと○円」の追加購入余地あり | 送料無料ラインを設定し明示 |

### 10. 在庫水準

**問い**: 在庫は多すぎないか、足りなくないか？
**データ**: 現在庫数・注文可能数 + 期間別販売数 → 在庫回転日数（在庫数 ÷ 日次販売数）

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 在庫回転日数が7日未満 | 欠品リスクが高い | 発注数の見直し・在庫アラート設定 |
| 在庫回転日数が90日超 | 仕入れ過多または死筋 | 価格見直し・在庫処分セール |
| 注文可能数が0 | 現在購入できない | 在庫補充または再入荷お知らせの活用 |

### 11. バリエーション別売れ行き

**問い**: 売れている色・サイズと、余っている色・サイズはどれか？
**データ**: バリエーション・オプションを商品・期間ごとに集計 + バリエーション別の在庫数・注文可能数

商品単位では「在庫は十分」に見えても、売れ筋バリエーションだけ欠品して機会損失が出ていることがある。

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 特定バリエーションに販売が集中 | 人気と死筋が混在 | 人気の在庫を優先確保、死筋の廃番・値引き処分 |
| 人気バリエーションの注文可能数が0 | 機会損失が発生中 | 優先発注・再入荷お知らせの活用 |
| 特定バリエーションの在庫が極端に多い | 需要予測の誤りまたは仕入れ偏り | 在庫処分セール・まとめ買い割引 |
| 全体で販売が少ない | 商品単位の問題 | 他観点で掘り下げる |

### 12. 値引き・ポイント反応

**問い**: 値引きすると売れる商品か？
**データ**: クーポン利用・ポイント利用・割引率。割引あり期間と通常期間の販売数を比較

| パターン | 読み取れること | 接続先 |
|---|---|---|
| セール時に販売数が大きく増える | 価格弾力性が高い | 割引の頻度・率・期間を設計し直す |
| セールしても販売数が変わらない | 価格感度が低い | 説明文・画像など価格以外の施策に投資する |
| ポイント利用が多い注文でリピートが増える | ポイント感度が高い顧客層 | 定期的なポイントアップが有効 |
| クーポン利用が少ない | 配布が届いていない、条件が合っていない | 配布方法・最低購入金額の見直し |

### 13. キャンセル・返品

**問い**: 買ったあとにガッカリされていないか？
**データ**: 注文ステータス（キャンセル）・返品件数を商品ごとに集計

売上は注文時点の数字であり、その後のキャンセル・返品を引かないと実態より良く見える。

| パターン | 読み取れること | 接続先 |
|---|---|---|
| キャンセル率が高い | 注文後に気が変わる要素がある | 納期・送料・在庫状況を購入前に明示 |
| 返品が多い | サイズ感・色味・品質が期待と違う | 説明文・画像を現物に忠実に修正、サイズ表の追加 |
| ほぼない | 購入後の満足に問題なし | 購入前（流入・転換）の観点に集中 |

### 14. デバイスタイプ

**問い**: スマホとPC、どちらで買われている商品か？
**データ**: 注文デバイス（スマホ / PC）の比率

| パターン | 読み取れること | 接続先 |
|---|---|---|
| スマホ注文が70%以上 | スマホ体験が購買を左右している | 縦長・正方形画像の用意、説明文の短文化 |
| PC注文が多い | 比較検討に時間をかける商品 | 詳細な仕様説明・スペック表・比較情報を追加 |

### 15. ギフト購入の割合

**問い**: 自分用に買われているか、贈りもの用に買われているか？
**データ**: 注文者都道府県と送付先都道府県の一致・不一致 + 配送希望日時の指定有無・日付分布

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 注文者 ≠ 送付先が30%以上 | ギフト需要がある | ギフト訴求を追加、のし・ラッピング対応を明示 |
| 配送希望日がイベント前後に集中 | 季節に連動したギフト需要 | イベント前の事前訴求・セール設計 |
| 注文者 ≠ 送付先で日付指定なし | 急ぎのギフト需要 | 即日・翌日配送対応の訴求 |
| 注文者 = 送付先がほぼ100% | 自家使用商品 | 日常使い・実用性・コスパの訴求に集中 |

### 16. 定期購入の定着度

**問い**: 定期的に買い続けてもらえる商品か？
**データ**: 定期購入として受けた注文かを商品ごとに集計し、全注文に対する比率を算出

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 定期購入の注文が多い | 定期需要が浸透している | 継続者向けの送料割引・ポイント特典を明記し、解約防止を設計 |
| 繰り返し購入はあるが定期購入が使われていない | プランが使われていない | 定期購入プランの導入・訴求を検討 |
| 定期購入がほぼない単発購入 | 定期需要がない | まとめ買い・セット販売を優先 |

### 17. リピートとLTV

**問い**: この商品は、お客さんを「また買いに来る常連」に育てているか？
**データ**: 会員IDと注文日時・金額から、初回購入商品・累計購入金額・購入間隔を算出

初回購入で利益が出なくても後で大きく伸びる商品がある。商品単体の1回の売上だけで判断すると、優良な「入口商品」を切り捨てる誤りが起きる。

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 初回購入後のリピート率が高い | 新規獲得に使える入口商品 | 広告・販促の重点商品に位置づける |
| 初回購入後のリピート率が低い | 単発買いで終わっている | 再購入クーポン・ポイント付与の設計 |
| 購入間隔が一定で短い | 消耗品・嗜好品で定期需要がある | 定期購入プラン・まとめ買い割引の検討 |
| 優良顧客に売れている | 優良顧客が選ぶ商品 | 説明文で「繰り返し選ばれる理由」を訴求 |

### 18. 純利益ベースの採算

**問い**: 売ったあと、手元にいくら残っているか？
**データ**: 仕入価格 + 割引額・ポイント付与額・送料・決済手数料 + 返品件数

```
実質利益 = 売上 − 仕入原価 − 割引額 − ポイント付与コスト − 送料コスト − 決済手数料 − 返品コスト
```

| パターン | 読み取れること | 接続先 |
|---|---|---|
| 粗利率は高いが割引・ポイント利用が集中 | 実質利益は粗利率を大きく下回る | 割引頻度・ポイント倍率の見直し |
| 送料が発生する注文が多く単価が低い | 送料コストが利益を圧迫 | 送料無料ラインの引き上げ、セット化で単価向上 |
| 特定の決済手段に集中 | 手数料コストが高い決済に偏っている | 推奨決済手段の変更や誘導 |
| 返品件数が多い | 期待と現物のギャップ | 説明文・画像を現物に近い表現へ修正 |
