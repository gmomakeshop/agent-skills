# 商品名

商品名は「検索でヒットさせる」「一覧でクリックさせる」の2つを同時に担う。文章ではなく、検索される単語を半角スペースで区切って並べて構成する。

## ベストプラクティス

### 1. カテゴリ語・特徴語・用途語の複合キーワードで構成する

抽象的なネーミングだけでは検索にヒットせず、一覧でも何の商品かが伝わらない。ビッグキーワード単体では大手に埋もれるため、「カテゴリ語 + 特徴語 + 用途語」の複合で購買意欲の高い検索を拾う。キーワードは机上で考えず、自分が顧客としてその商品を探すなら何と入力するかを実際に検索して確かめる。

- 悪い例：`しあわせの一粒` — 何の商品か伝わらず、「コーヒー」「珈琲豆」でヒットしない
- 良い例：`自家焙煎コーヒー豆 中深煎り 200g 挽き方選択可`

### 2. 重要な情報ほど先頭に置く

商品一覧やスマートフォンでは先頭の20〜30文字程度しか表示されず、表示環境によっては全角23文字前後で省略される。最重要キーワードは冒頭15文字以内を目安に置き、切れても支障のない補足語を後方に回す。書き終えたらスマートフォンの一覧で実際にどこで切れるかを確認する。

- 悪い例：`毎日の食卓にちょっとした彩りを添えてくれる 天然木カトラリーセット`
- 良い例：`木製カトラリーセット 4本組 天然アカシア 食洗機対応 ギフト`

### 3. 全角30文字前後を目安にし、上限まで詰め込まない

入力上限は255文字だが、長い商品名は可読性を下げ、羅列としてスパム判定されるリスクがある。目安は主要キーワードを収めた全角30文字前後、補足語を含めても50文字以内。収まらない関連語は検索語へ逃がす（`references/settings-reference-search-keywords.md`）。

### 4. サイズ・容量・数量・型番など具体的な数字を入れる

「大きめ」「たっぷり」では購入イメージが湧かず、サイズ違いのクレームになりやすい。規格違いの多いジャンル（サプリ・コスメ・食品・家電）ほど容量・数量・対応サイズの明示が効く。型番のある商品は型番検索の顧客が購買意欲が高いため必ず含める。数字は半角で統一する。

### 5. ブランド名は知名度に合わせて配置する

指名検索されるブランドは先頭に置くと、一覧での識別性と指名検索のヒット率が上がる。指名検索が見込めない場合は、貴重な先頭の文字数をブランド名で消費せず、カテゴリ語を先頭にしてブランド名は後方か【】区切りで添える。

### 6. 誰向け・どんなシーンかが伝わる語を入れる

スペックが同等の競合が並んだとき、顧客は「自分向けの商品か」で選ぶ。ターゲット語（メンズ・ベビー・敏感肌用）やシーン語（通勤・アウトドア・ギフト）は、絞り込み検索のヒットと一覧での自分ごと化の両方に効く。

### 7. 英数字は半角・カタカナは全角に統一する

「Ｌサイズ」と「Lサイズ」は検索環境によって別の文字列として扱われ、表記が揃っていないと検索を取りこぼす。単語間は半角スペース1つ。半角カタカナは使わない。「/」「・」「、」での区切りは単語の切れ目が認識されにくいため、区切りは半角スペースを基本にする。表記規則をルール表にして、誰が登録しても同じ表記になる状態にする。

### 8. 機種依存文字・環境依存文字・絵文字を使わない

①②・㈱・♥・絵文字は閲覧環境によって文字化けし、登録時に弾かれたりコード表記に変換されたりする場合がある。変換で文字数が膨らみ、上限を超えた分が警告なく切り捨てられることもある。丸数字は半角数字、㈱は（株）、ローマ数字は半角英字に置き換える。HTMLタグも商品名では動作せず文字列のまま表示される。

### 9. 最上級表現・効能表現・記号・販促ワードを使わない

- 「日本一」「最安」などの最上級・No.1表現は、客観的な調査による合理的根拠がなければ景品表示法上の問題になるおそれがある
- 「痩せる」「治る」「シミが消える」などの効能効果の表現は、医薬品等でない商品では薬機法違反のリスクがある
- 「★」「！」などの装飾記号や「送料無料」「期間限定」は説明文・割引設定で伝える情報であり、商品名に入れると本質的な商品情報が埋もれる

### 10. キーワードの羅列・実態と異なる語を入れない

同じ語の繰り返しや詰め込みすぎはスパムと判定されるリスクがある。実態と異なる語（ノーブランド品への有名ブランド名の便乗など）は、クリックされても「思っていたのと違う」で直帰される。各語は1回ずつ、詰め込みたい語は類語・関連語に置き換える。表記ゆれは商品名ではなく検索語で拾う。

### 11. 色・サイズ展開は羅列せず集約する

色名・サイズ名の羅列は前半の貴重な文字数を消費する。「全5色」「S-XL」のような集約表現でまとめ、個別の色・サイズはバリエーション設定側で持たせる。ただし「白Tシャツ」「黒スニーカー」のように色がそのまま検索される商品は、代表色を1語だけ入れる価値がある。

### 12. ジャンル別の構成の型に当てはめる

商品名を組み立てる・診断する際の型として使う。画像やバリエーション設定で伝わる要素は省略してよい。

| ジャンル | 構成 | 例 |
|---|---|---|
| ファッション | ブランド名 商品名称 性別 シーズン 仕様 色 サイズ | リブニットワンピース レディース 秋冬 ウール混 グレー M-L |
| 食品 | メーカー名 ブランド名 商品名称 仕様 内容量 数量 | 朝採れトマトジュース 食塩無添加 720ml 6本セット |
| 家電・ガジェット | メーカー名 ブランド名 商品名称 色 仕様 型番 | ワイヤレスイヤホン ブラック ノイズキャンセリング 型番XY-100 |
| コスメ・健康 | ブランド名 商品名称 仕様 容量 | 薬用美白美容液 敏感肌用 30ml |
| インテリア・雑貨 | ブランド名 商品名称 素材 サイズ 色 | ウッドシェルフ 3段 オーク材 幅60cm ナチュラル |

## 症状別の打ち手

改善は1商品につき1要因ずつ変更し、2〜4週間後にPV・CVRを変更前と比較して効果を判定する。

| 症状 | 状態 | 打ち手 |
|---|---|---|
| PVが少ない | 検索でヒットしていない | 顧客が検索する語（カテゴリ・特徴・用途・ターゲット）を追加する（1）。伸びなければキーワード自体に需要がないと判断して入れ替える |
| CVRは高いのにPVが少ない | 見た人は買っているが見られていない | 最優先の改善対象。検索語の追加で流入を増やす。注文データと商品別PVの突き合わせで探し出す |
| ビッグワードで埋もれる | 大手・広告が上位を占めている | サジェストから勝てる絞り込みの組み合わせ（ロングテール）に具体化する（1） |
| 表示されるがクリックされない | 前半で差別化できていない | 数字や差別化要素を前半20〜30文字に凝縮する。後半の重要語を前半に移す（2） |
| 誰向けか伝わらない | ターゲット・シーンが不明 | ターゲット語・シーン語を追加する（6） |
| アクセスはあるが買われない | 期待値とページの中身がズレている | 曖昧な表現を数字に置き換え、誇大な表現・実態と異なる語を削る（4、10） |
| 競合と同質化している | 価格でしか比較されない | 上位競合の商品名を3〜5件書き出し、共通要素は揃えたうえで自社独自の強み（製法・保証・産地）を加える |
| 型番検索を取りこぼす | 型番・規格が入っていない | 型番を末尾に置く。独自商品コードも型番に合わせる（`references/settings-reference-search-keywords.md`） |
| 表記ゆれを取りこぼす | 略称・悩み語が拾えていない | 商品名には代表語だけを置き、表記ゆれ・略称・悩み語は検索語で補完する（`references/settings-reference-search-keywords.md`） |
| 全角・半角が混在 | 商品ごとに表記がバラバラ | 半角・全角それぞれでテスト検索し、規則で一括修正する。CSV出力で混在を洗い出す（7） |
| 商品名が長すぎる | 一覧で前半の修飾語しか出ない | 全角30文字前後に刈り込み、削った語は検索語へ移す（2、3） |
| 指名買いされている | ブランドが認知され始めた | ブランド名を先頭に置き、指名検索・再購入の導線を強くする（5） |
| シリーズの関係が伝わらない | 名称がバラバラ | 「シリーズ名 + 商品名称 + 違いが分かる語」に揃える（11、12） |
| 季節で需要が動く | 検索される語が変わる | 需要期の1か月前に季節・イベント語へ入れ替え、需要期後に戻す運用までセットにする |
| 変更の効果が分からない | 検証していない | 変更前のPV・販売数・CVRを控え、2〜4週間後に比較する。1回の変更は1要因に絞る |

効果判定の読み方：PVが増えCVRが横ばいなら流入増がそのまま売上増。PVが増えCVRが下がったなら期待値とズレる語が混ざっている。どちらも動かないなら選んだ語に需要がない。
