# セグメント分析

顧客を購買行動に基づいて分類し、セグメントごとの規模と特性を把握し、各フェーズにおけるボトルネックと成長機会を特定する。

各セグメントに適した施策を設計する。

## 分析方法

### 初回購入会員群

#### 定義
累計購入回数が1回のみの会員。

#### 用途
育成対象として抽出し、ステップ配信（購入後○日でフォロー、○日後にクーポン送付など）を設計する。

#### 計算方法
1. 全注文データから会員IDごとに注文回数をカウントする
2. 注文回数が1回のみの会員を抽出する
3. 会員数と売上金額を集計する

### リピート会員群

#### 定義
累計購入回数が2回以上の会員。

#### 用途
継続顧客として把握し、継続促進施策（ポイント、ランク制度、定期購入など）を検討する。

#### 計算方法
1. 全注文データから会員IDごとに注文回数をカウントする
2. 注文回数が2回以上の会員を抽出する
3. 会員数と売上金額を集計する

### 高LTV会員群

#### 定義
全会員のうち、累計購入金額が上位20%に該当する会員。

#### 用途
優良顧客像を把握し、VIP施策（限定セール、先行販売、個別対応）を検討する。
優先で維持すべき優良顧客。特別体験の提供や、アップセル・クロスセルのターゲットとして活用

#### 計算方法
1. 全注文データから会員IDごとに決済合計金額を合計する
2. 全会員の累計金額の上位20%を閾値として設定する
3. 閾値以上の会員を抽出する
4. 会員数・売上金額・平均購入回数を集計する

### 離脱懸念会員群

#### 定義
最終購入経過日数が「個別の平均購買間隔」の1.5〜2倍を超えているが、まだ休眠には至っていない会員。

#### 用途
「忘れられつつある」段階での早期引き戻し。平均購買間隔直前のリマインド配信より強力なアプローチ（個別クーポン等）が必要

#### 計算方法
1. 全注文データから会員IDごとに平均購買間隔を算出する
2. 各会員の最終購入日から現在までの経過日数を算出する
3. 経過日数が平均購買間隔の1.5〜2倍を超える会員を抽出する
4. 会員数と直近の購入金額を集計する

### 休眠会員数

#### 定義
最終購入から一定期間（例: 90日、180日）購入がない会員の数。休眠規模を示す。

#### 用途
休眠復活施策の対象。施策のROI（費用対効果）を精査し、復活した会員のLTVを追跡する。
再活性化施策（復帰クーポン、新商品案内）の規模見積もりに使う。

#### 計算方法
1. 全注文データから会員IDごとに最新の注文日時を取得する
2. 現在日付との差分を日数で算出する
3. 90日以上、180日以上など閾値ごとに会員数をカウントする
