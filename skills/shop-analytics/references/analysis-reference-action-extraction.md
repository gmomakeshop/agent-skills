# 施策抽出

特定条件に合致する会員を抽出し、具体的な施策の対象とする。分析結果を「誰に何をするか」のアクションに落とし込む。

## 分析方法

### 初回後○日未再購買会員

#### 定義
初回購入後、一定期間（例: 30日、60日）再購入していない会員。

#### 用途
2回目購入を促進するフォロー配信の対象とする。

#### 計算方法
1. 全注文データから会員IDごとに注文回数をカウントする
2. 注文回数が1回のみの会員を抽出する
3. 初回注文の注文日時から現在までの経過日数を算出する
4. 経過日数が指定期間（30日、60日など）を超える会員をリストアップする

### 最終購入後○日経過会員

#### 定義
最終購入から一定期間経過した会員。

#### 用途
休眠防止のための掘り起こし施策（リマインドメール、復帰クーポン）の対象とする。

#### 計算方法
1. 全注文データから会員IDごとに最新の注文日時を取得する
2. 現在日付との差分を日数で算出する
3. 経過日数が指定期間（60日、90日、180日など）を超える会員をリストアップする

### 高LTV失速会員

#### 定義
過去の購入実績は高いが、直近の購入が止まった会員。

#### 用途
離脱防止のための個別優遇施策（パーソナルオファー、限定クーポン）の対象とする。売上インパクトが大きいため優先度が高い。

#### 計算方法
1. 全注文データから会員IDごとに累計決済合計金額を算出する
2. 累計金額が上位20%の会員を特定する
3. 上位会員のうち、最終購入日から現在までの経過日数が平均購買間隔の2倍以上の会員を抽出する

### 特定商品購入会員

#### 定義
指定した商品を購入した会員のリスト。

#### 用途
関連商品の提案（クロスセル施策）の対象とする。新商品発売時に、関連する既存商品の購入者にアプローチする。

#### 計算方法
1. 全注文データから、指定した商品名またはシステム商品コードを含む注文を抽出する
2. 該当注文の会員IDをユニークでリストアップする
3. 各会員の購入回数・累計金額を集計する

### 優良顧客候補会員

#### 定義
平均注文回数以上購入しており、なおかつ累計購入金額が高い会員

#### 用途
育成対象として抽出し、会員ランク施策（次のランクまであと○円で特典付与など）の対象とする。

#### 計算方法
1. 全注文データから会員IDごとに注文回数をカウントする
2. 平均注文回数以上注文している会員を抽出する
3. 直近の購入日が比較的近い（平均購買間隔の2倍以内）会員に絞る
4. 会員数・平均購入金額を集計する
