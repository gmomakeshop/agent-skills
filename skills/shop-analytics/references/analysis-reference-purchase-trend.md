# 購買傾向分析

曜日・時間帯・月・購入回数など、時間軸や行動軸に沿った購買パターンを分析する。月ごと・曜日ごとの売上推移を分析する。販促のタイミング最適化や季節に合わせた仕入れ計画に活用する。

## 分析方法

### 曜日別購入傾向

#### 定義
曜日ごとの注文件数・売上の傾向。

#### 用途
1.曜日ごとの売り上げ傾向を把握する。
2.販促タイミングを最適化する。
3.注文が多い曜日にメルマガやLINE配信を合わせることで効果を最大化する。

#### 計算方法
1. 対象期間の全注文を取得する
2. 各注文の注文日時から曜日を抽出する
3. 曜日ごとに注文件数と決済合計金額の合計を集計する
4. 「キャンセル」「返品」になった注文は集計から除外する

### 時間帯別購入傾向

#### 定義
時間帯ごとの売上・注文件数の傾向。

#### 用途
配信時間を最適化する。ピーク時間帯に合わせて広告配信やLINE通知のタイミングを調整する。

#### 計算方法
1. 対象期間の全注文を取得する
2. 各注文の注文日時から時間帯（0〜23時）を抽出する
3. 時間帯ごとに注文件数と決済合計金額の合計を集計する
4. 「キャンセル」「返品」になった注文は集計から除外する

### 月別購入傾向

#### 定義
月ごとの購入傾向。季節性を示す。

#### 用途
月別の販促計画や仕入れ計画に活用する。毎年同じ月に落ち込む傾向があればテコ入れ施策を準備する。

#### 計算方法
1. 対象期間（通常は1年分以上）の全注文を取得する
2. 各注文の注文日時から年月を抽出する
3. 月ごとに注文件数と決済合計金額の合計を集計する
4. 「キャンセル」「返品」になった注文は集計から除外する

### 購入回数帯別商品傾向

#### 定義
1回目、2回目、3回目で買われる商品の傾向。

#### 用途
育成導線を把握し、購入回数に応じたレコメンドを設計する。
定期購入として導入が見込めそうな商品とサイクルを設計する。

#### 計算方法
1. 全注文データから会員IDごとに注文を注文日時で時系列ソートし、各注文に購入回数（1回目、2回目、3回目…）を付与する
2. 購入回数帯（1回目、2回目、3回目、4回目以降）ごとに、注文に含まれる商品を集計する
3. 各回数帯での商品別出現回数をカウントし、降順ソートする
