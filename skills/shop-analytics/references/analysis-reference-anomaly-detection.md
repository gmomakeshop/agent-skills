# 異常検知

不正や異常な注文パターンを検知し、早期対応につなげる。通常とは異なる注文を自動的に検出し、監視対象として抽出する。

## 分析方法

### 高額注文数

#### 定義
通常より高額な注文の件数。

#### 用途
不正注文や法人注文などの異常を把握する。高額注文が急増した場合は個別確認や与信チェックを行う。

#### 計算方法
1. 対象期間の全注文を取得する
2. 全注文の決済合計金額の平均値と標準偏差を算出する
3. 平均値 + 標準偏差×3 を閾値とする
4. 閾値を超える注文をカウントし、リストアップする

### 短時間連続注文

#### 定義
同一会員による短時間内の連続注文。

#### 用途
不正注文の兆候を確認する。短時間に大量注文がある場合は確認フローを強化する。

#### 計算方法
1. 対象期間の全注文を取得する
2. 会員IDごとに注文を注文日時で時系列ソートする
3. 連続する注文間の時間差を算出する
4. 時間差が一定以下（例: 10分以内）の注文が複数ある会員を抽出する

### 初回高額注文

#### 定義
初回会員による高額注文。

#### 用途
初回で異常に高額な注文はリスクがあるため、審査を強化する。

#### 計算方法
1. 対象期間の全注文から初回注文を特定する
2. 初回注文の決済合計金額の平均値と標準偏差を算出する
3. 平均値 + 標準偏差×3 を閾値とする
4. 閾値を超える初回注文をリストアップする

### 異常点数注文

#### 定義
通常より商品点数が多い注文。

#### 用途
転売目的や不正注文の可能性を確認する。異常点数の注文は個別に確認する。

#### 計算方法
1. 対象期間の全注文を取得する
2. 各注文に含まれる商品の数量を合計し、注文あたりの総点数を算出する
3. 全注文の総点数の平均値と標準偏差を算出する
4. 平均値 + 標準偏差×3 を閾値とする
5. 閾値を超える注文をリストアップする
