# ショップ分析スキル

利用可能な注文・会員データ取得ツールを通じてデータを取得し、売上分析・問題検知・レポート作成・施策提案を行う。

## ワークフロー

### 1. ヒアリング

以下の項目をすべて明確にしてから次工程に進む。ユーザーの発話から推測できる項目は確認なしで進めてよいが、曖昧な場合は必ず聞き返す。

| 項目 | 確認内容 |
|---|---|
| 分析テーマ | 何を知りたいか・何を解決したいか（例: 「売上推移」「売上低下の原因」「リピート施策の提案」） |
| 分析対象指標 | テーマに対して具体的にどの指標を出すか（例: 「平均LTV」「LTV上位会員数」） |
| 対象期間 | いつからいつまでのデータを対象とするか |
| 出力形式 | テキスト or HTML |

#### 1-1. 分析テーマの聞き取り

ユーザーから「何を知りたいか・何を解決したいか」を聞く。曖昧な表現の場合は意図を確認する。

#### 1-2. 分析対象指標の具体化

テーマだけでは何を算出すべきかが定まらないため、**指標レベルまで具体化してユーザーと合意を取る**。

**スキップ条件**: ユーザー発話の中で具体的な指標が明示されている場合（例: 「今月の売上推移と客単価を見せて」「平均LTVだけ知りたい」）は、提案による確認を省略して 1-3 に進む。曖昧な指標が1つでも残っていれば実施する。

**該当リファレンスの特定（決定木）**:

1. 依頼が **日次/週次/月次/ダッシュボード等の複合レポート** → 「複合レポートのレシピ」を起点に、構成要素のリファレンスを順に特定
2. 依頼が **単一テーマ**（売上、リピート、LTV など） → 「ユーザーリクエスト → 参照リファレンス」表で該当行を引く
3. 上記いずれにも当てはまらない曖昧な依頼 → 「キーワード索引」で発話に含まれる単語から候補を絞り、候補が複数あれば「ユーザーリクエスト → 参照リファレンス」表で文脈に合うものを選ぶ

**手順**:

1. 上記決定木で該当する分析リファレンスを特定する
2. 特定したリファレンスを読み込み、定義されている指標を把握する
3. テーマに合った指標を2〜4個に絞ってユーザーに提案し、確認を取る

提案例:
> ユーザー: 「LTVを分析したい」
> Claude: `references/analysis-reference-ltv.md` を確認 → 「平均LTVとLTV上位会員数を分析対象にしますが、いかがでしょうか?」

ユーザーが指標の追加・削除を求めた場合は調整する。指標が増減すれば後段の取得項目も変わる。

#### 1-3. 対象期間

| ユーザーの表現 | 対象期間 | 比較対象 |
|---|---|---|
| 「今月の売上」「今月はどう」 | 当月1日〜本日 | 前月同期間 |
| 「先月の売上」 | 前月1日〜前月末日 | 前々月 |
| 「最近の売上」「売上はどう」 | 直近1ヶ月 | その前の1ヶ月 |
| 「今年の売上」 | 当年1月1日〜本日 | 前年同期間 |
| 明示的な期間指定 | 指定期間 | 同じ長さの直前期間 |

#### 1-4. 出力形式

「グラフで見たい」「ダッシュボード」→ HTML、「簡潔に教えて」「会話で報告」→ テキスト。

### 2. 取得項目の確認

必要なフィールドだけを取得して実行時間を短縮する。ツールを複数回実行する場合は、ユーザーに許可をとってから実行する。

手順:

1. 1-2 で特定した分析リファレンスの「計算方法」を読み、算出に必要なデータ要素を洗い出す（例: 会員ID、注文金額、注文日時、商品名、商品単価、数量）
2. **出力形式が HTML の場合は、この時点で `references/report-reference-html.md` も読み込み、ダッシュボード描画に必要なラベル系フィールド（商品名、システム商品コード、都道府県など）を洗い出しに加える**。テキスト出力でも、表に乗せたい属性があれば同様に追加する
3. データ取得ツールが必要なフィールドへの絞り込みに対応している場合は、絞り込みを行う

### 3. データ取得

1. 注文取得ツールで **対象期間** の全注文データを取得する。2 で絞り込んだ条件・フィールド指定を使う
2. **比較対象期間がある場合**（1-3 の表で定義された前月・前年同期間など）は、同じ条件で **比較期間** の全注文データも取得する。前期比・前年比の算出に必須
3. 会員属性が必要な場合、会員取得ツールで会員データを取得する。

### 4. 分析・出力

1. リファレンスの計算方法に従い分析を実施する
2. 分析カテゴリに応じた構成で結果をまとめる
   - **売上把握・KPI確認**: 指標の算出 → 前期間との比較 → KPIツリーによる変動要因の分解 → 次のアクションへの示唆
   - **問題検知・原因分析**: 概況把握 → 問題の特定（Where） → 原因の深掘り（Why） → 影響範囲の算出 → 対応策の提示
   - **レポート・資料作成**: サマリー（結論先出し） → 基本指標の算出 → 前期間比較 → 注目トピックの深掘り → 推奨アクション
   - **戦略・施策提案**: 現状分析 → 課題の特定 → 施策提案（誰に・何を・いつ・どのように） → 期待効果の試算 → 優先順位付け
3. レポートリファレンスを参照し、指定された形式で出力する

## 分析リファレンス一覧

各ファイルの担当領域。

| ファイル | テーマ | 主要指標・対象 |
|---|---|---|
| `references/analysis-reference-basic.md` | 基本KPI | 購買会員数・受注件数・売上金額・客単価・会員あたり売上/購入回数 |
| `references/analysis-reference-new-existing.md` | 新規/既存比較 | 新規/既存購入会員数、新規/既存売上比率、新規客/既存客客単価 |
| `references/analysis-reference-purchase-trend.md` | 時系列・行動パターン | 曜日別・時間帯別・月別購入傾向、購入回数帯別商品傾向 |
| `references/analysis-reference-repeat.md` | リピート分析 | 2回目/3回目購入率、リピート率、累計購入回数別会員数、平均購買間隔、初回→2回目日数、最終購入経過日数 |
| `references/analysis-reference-rfm.md` | RFM分析 | Recency・Frequency・Monetaryの3軸スコア、RFM上位会員数、掘り起こし優先会員数 |
| `references/analysis-reference-segment.md` | 顧客セグメント | 初回購入会員群、リピート会員群、高LTV会員群、離脱懸念会員群、休眠会員数 |
| `references/analysis-reference-ltv.md` | 顧客生涯価値 | 会員別累計購入金額、平均LTV、LTV上位会員数、上位会員売上構成比 |
| `references/analysis-reference-churn.md` | 段階別離脱 | 離脱タイミング別会員数、初回/2回目離脱比率、離脱前購入商品 |
| `references/analysis-reference-first-buyer.md` | 初回客 | 初回購入商品、初回購入金額帯/点数、初回客離脱率、初回客次回購入商品 |
| `references/analysis-reference-loyal-customer.md` | 優良顧客 | 売上/購入回数上位会員、優良顧客の平均購買間隔、初回購入商品、優良顧客化までの平均日数 |
| `references/analysis-reference-product-combination.md` | 商品組合せ | よく一緒に買われる商品、組合せ別売上、初回同時購入商品、リピーター追加購入商品 |
| `references/analysis-reference-anomaly-detection.md` | 異常検知 | 高額注文数、短時間連続注文、初回高額注文、異常点数注文 |

## ユーザーリクエスト → 参照リファレンス

「主」が必須、「補」は深掘りやレポート向け。複合的なレポート作成は後段の「複合レポートのレシピ」を参照。

### 売上把握・KPI確認

| リクエスト | 主 | 補 |
|---|---|---|
| 売上推移、売上規模、客単価、KPI全般 | basic | new-existing, purchase-trend |
| 商品別売上ランキング、売上構成 | basic | purchase-trend, product-combination |
| 時間軸の売上パターン（曜日/時間帯/月） | purchase-trend | basic |
| 新規/既存の構成と貢献度、新規顧客率 | new-existing | basic, ltv |
| 顧客属性別売上 | basic | new-existing, ltv, rfm |

### 顧客行動の分析

| リクエスト | 主 | 補 |
|---|---|---|
| リピート率、購買間隔、再購入動向 | repeat | churn, segment |
| RFMスコア、優良顧客の階層化、掘り起こし対象 | rfm | segment, ltv |
| 顧客生涯価値（LTV）、上位会員構成比 | ltv | loyal-customer, rfm |
| 顧客セグメント分類（初回/リピート/休眠等） | segment | repeat, churn |
| 初回客分析（入口商品、初回金額帯） | first-buyer | new-existing, action-extraction |
| 優良顧客分析、優良化までの日数 | loyal-customer | ltv, rfm |

### 問題検知・原因分析

| リクエスト | 主 | 補 |
|---|---|---|
| 売上不振・KPI悪化の原因分析 | basic + segment | churn, purchase-trend, anomaly-detection |
| 顧客離反・休眠の分析 | churn | segment, action-extraction |
| 死に筋商品・リピート率が低い商品 | purchase-trend | basic, churn, product-combination |
| 異常注文・不正の検知 | anomaly-detection | basic |

### 戦略・施策提案

| リクエスト | 主 | 補 |
|---|---|---|
| 顧客育成・リピート促進・ステップ配信 | action-extraction + first-buyer | repeat, loyal-customer |
| クロスセル・アップセル・セット販売 | product-combination | first-buyer, loyal-customer, purchase-trend |
| 優良顧客・VIP施策 | loyal-customer | rfm, ltv, action-extraction |
| 購入サイクルに合わせた施策設計 | action-extraction | repeat, purchase-trend, loyal-customer |
| 商品改廃・新商品企画・価格改定 | product-combination | purchase-trend, first-buyer, loyal-customer |
| 広告施策、キャンペーン効果測定 | basic + new-existing | purchase-trend, segment |

## 複合レポートのレシピ

複数リファレンスを組み合わせて作成するレポート。読む順番は推奨順。

### 日次売上報告
1. basic（前日比、客単価）
2. anomaly-detection（異常注文の有無）
3. purchase-trend（時間帯ピーク）

### 週次売上報告
1. basic（前週比、客単価）
2. new-existing（新規/既存内訳）
3. repeat（2回目購入率の推移）
4. anomaly-detection
5. purchase-trend, product-combination（注目トピックがあれば）

### 月次売上報告
1. basic（前月比・前年同月比）
2. new-existing
3. repeat（リピート率、2回目購入率推移）
4. rfm（階層別会員数）
5. ltv（平均LTV、上位構成比）
6. segment（セグメント規模変動）
7. anomaly-detection
8. purchase-trend
9. action-extraction（次月の施策対象会員）

### 売上ダッシュボード
1. basic（KPIタイル）
2. new-existing（新規/既存内訳）
3. repeat（リピート率推移）
4. rfm（マトリックス）
5. segment（セグメント規模バー）
6. purchase-trend（曜日/時間帯/月別ヒートマップ）
7. anomaly-detection（アラート）
